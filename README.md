# DSF Compliance Quickcheck

**DSGVO-Compliance für KMUs im DACH-Raum — schnell, rechtssicher, bezahlbar.**

Entwickelt von [DSF Consulting](https://github.com/AirFun1311), Fürth/Nürnberg.

---

## Was wird geliefert

- VVT — Verzeichnis von Verarbeitungstätigkeiten (Art. 30 DSGVO)
- DSFA — Datenschutz-Folgenabschätzung (Art. 35 DSGVO)
- AVV — Auftragsverarbeitungsvertrag Checkliste (Art. 28 DSGVO)
- Automatischer Website-Scan (HTTPS, Datenschutzerklärung, Cookie-Banner, SSL)

## Für wen

Kleine und mittlere Unternehmen in Deutschland und Österreich die DSGVO-konform werden müssen — ohne teuren Anwalt.
